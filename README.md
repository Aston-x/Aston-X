## 🌐 English Summary

Hi, I'm **Aston-x** (季怡) — a developer who mostly writes **Python** and **TypeScript**.

My main project is **[Xuxingjiu](https://github.com/Aston-x/xuxingjiu)**, a QQ bot with a
personality: it lives in a second-hand bookshop, keeps a daily routine, has mood levels and a
two-layer memory, and talks to you through a pluggable model layer — point it at a local 7B
model or a cloud API, your call.

- 🔧 **Stack:** Python · TypeScript · Node.js · LLM applications · Docker · GitHub Actions
- 🧠 **Focus:** character consistency, long-term memory, and a provider-agnostic model layer
- 🌱 **Learning:** keeping the character in role, and making memory survive across sessions
